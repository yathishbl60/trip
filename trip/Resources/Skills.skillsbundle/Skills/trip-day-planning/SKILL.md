description: Help plan or adjust a day in a saved Trip itinerary, work out what comes next, or change how long to spend at a saved place. Use for requests such as plan my day, allow more time, fit this visit around my flight, or what is next. Not for creating or changing a real booking, or packing a bag.

# Plan a saved travel day

Identify the saved trip and day first. Trips with the same name can have different
departure dates. Ask when the intended trip or day is ambiguous.

Use Read My Trip Day before coordinating several changes to that day. For an
immediate next-step question, use Get What's Next in My Trip. Times are saved
plans in the relevant destination time zones, not live departure predictions.
Flights and stays can cross dates and time zones. Never infer a missing booking
time or claim that a saved booking is currently confirmed.

For an explicit timing change, use Set Visit Timing on the exact saved place.
Keep unspecified timing fields unchanged. Travel and buffer minutes are personal
allowances, not route estimates. Ask for the intended local arrival time if it is
ambiguous. A next-day arrival is relative to the visit's itinerary day.
For relative duration changes, read the resolved place's saved minute properties
first. If a value is missing, ask for the intended total rather than assuming zero.
Flights, stays, and reservations are separate records; do not edit their times
through the visit tool. If a clock needs daylight-saving review, explain the
returned issue and open that saved detail for the person to resolve it.

After requested changes, read the day again to describe the resulting plan.
If the person instead wants an AI-generated arrangement, use Draft Itinerary
with Apple Intelligence and explain that Trip opens a draft for review. Keep
processing on device unless the person explicitly chooses Private Cloud Compute.
Do not save a suggested plan or add destinations without a request.

Include weather only when the person asks. Distinguish unavailable weather from
good weather. Read-only questions must not mark places visited or modify a plan.

For directions, use Directions to Saved Place on the exact saved visit. This opens
Apple Maps; it does not start tracking or mark a visit complete. For a new place,
use Find a Place for My Trip with the name, trip, and day. The person selects a
MapKit result in Trip before it is saved.

Use Track Trip Day only when asked to track progress. Use Mark Saved Place Visited
only when the person explicitly reports that visit completed. It accepts the next
place of the tracked day or an already recorded visit; a different trip, booking,
or out-of-order place must not advance another stop. Explain a returned issue.
Use End Trip Day Tracking only when asked to stop tracking; it keeps recorded visits.

Use Move Saved Place to Day for an explicitly requested move within the same trip.
It keeps the visit's identity and local arrival clock on the destination day.
It does not move bookings or recalculate travel. Re-read the destination day afterward.
