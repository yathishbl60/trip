# Architecture decisions

Record decisions that change dependencies, state lifetime, persistent formats, or
public reuse contracts. Small local implementation choices belong in code review.
Use [the decision template](../../templates/decision.md), a sequential identifier,
and a descriptive filename. Supersede an old decision with a new one; keep the
reasoning available for later contributors and AI-assisted work.
